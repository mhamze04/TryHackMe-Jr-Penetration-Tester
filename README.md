# TryHackMe - Jr Penetration Tester Pathway

Suivi de ma progression sur le parcours **Jr Penetration Tester** de TryHackMe. Ce dépôt documente, module par module, les concepts appris, les outils utilisés et les méthodologies suivies lors des labs guidés.

## Présentation du Parcours

Le parcours Jr Penetration Tester couvre les bases du test d'intrusion : reconnaissance réseau, énumération web, failles applicatives courantes (OWASP Top 10), exploitation contrôlée en environnement de lab, et reporting. L'objectif est de construire une méthodologie solide avant de passer à des certifications offensives plus poussées (ex. PT1, OSCP).

## Certification visée

Préparation vers une certification de pentest junior.
